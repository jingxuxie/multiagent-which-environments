# Which Environments Teach Cooperation?

Theory-first, synthetic, CPU-only research on diagnostic exposure for compatible self-play.

The initial research package is being published with full proofs, code, tests, raw results, and a compiled manuscript. The reproducibility workflow will materialize the hash-verified source package, run the experiments, and publish the ordinary source files and generated artifacts.

Completed local validation: 74 passing tests; 120 random finite geometries; 300 structured checks; 400 interval witnesses; 1,200 calibration decisions on 600 datasets; 2,016 learned-policy runs; 11 scientific CSVs reproduced byte-for-byte. A 19-page manuscript includes negative results: inverse-gap weighting can outperform the proposed curriculum on mean cross-play, and independent-action policy gradient often does not reach the certified near-optimal set.

This is a substantive first research draft, not an independently reviewed or final-format submission. No LLM API, GPU, external dataset, or physical robot is used.
